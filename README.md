# Виртуальный 360° тур ИГН АлтГУ

Институт гуманитарных наук Алтайского государственного университета.

Сайт: https://berengow.github.io/ign-360-tour/

Палитра — фирменный тёмно-синий АлтГУ. Контакты с [ign.asu.ru](https://ign.asu.ru/) и страницы института на asu.ru.

## Куда класть панорамы

1. Equirectangular JPEG, соотношение 2:1, лучше 4096×2048.
2. Файл в `panoramas/`, превью в `panoramas/thumbs/` с тем же именем.
3. Новый объект в массиве `SCENES` в `js/tour.js`.
