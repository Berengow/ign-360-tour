# Виртуальный 360° тур ИГН АлтГУ

Статический сайт. Открывается через GitHub Pages, без сборки.

## Куда класть панорамы

1. Снимите equirectangular JPEG, соотношение сторон **2:1** (лучше 4096×2048 или выше).
2. Положите файл в `panoramas/`, например `panoramas/hall.jpg`.
3. Положите превью 16:9 в `panoramas/thumbs/` с тем же именем.
4. В `js/tour.js` в массиве `SCENES` поправьте `panorama`, `thumb`, название, описание и координаты хотспотов (`pitch`, `yaw`).

Сейчас в папке демонстрационные сферические снимки (примеры Pannellum и Poly Haven, CC0). Это не фотографии кампуса.
