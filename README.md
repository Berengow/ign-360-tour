# Виртуальный 360° тур ИГН АлтГУ

Статический сайт. Открывается через GitHub Pages.

Сайт: https://berengow.github.io/ign-360-tour/

## Куда класть панорамы

1. Снимите equirectangular JPEG, соотношение сторон **2:1** (лучше 4096×2048).
2. Положите файл в `panoramas/`, превью 16:9 — в `panoramas/thumbs/` с тем же именем.
3. В `js/tour.js` добавьте объект в массив `SCENES`: название, описание, `panorama`, `thumb`, координаты хотспотов.
